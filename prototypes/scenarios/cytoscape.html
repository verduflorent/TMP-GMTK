Scène sélectionnée

Clique une carte pour l'éditer. Déplace-la sur le tableau. Le bouton « Relier » permet de sélectionner une source puis une destination. Maintiens Maj et glisse une carte vers une autre pour tenter une liaison directe.

Prévisualisation de lecture — les rubriques seront ajoutées dans les phases suivantes.

Transitions

Les flèches correspondent aux transitions. Cliquer une flèche pour modifier son libellé ou sa destination. Les cycles et les liens parallèles sont autorisés.

Mode de comparaison : Cytoscape.js chargé depuis CDN. Utilise des scènes fictives ; pas de connexion à TMP-GMTK.
